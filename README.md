# Third-party source for Snowlark

This repository holds the source of the third-party components that [Snowlark](https://snowlark.org)
ships with changes. Each component has a folder of its own, keeps its original licence, and says which
upstream release it is based on and what was changed.

| Folder | Component | Licence | Upstream |
|---|---|---|---|
| [stylo](stylo) | Stylo, the CSS engine of Servo and Firefox | Mozilla Public License 2.0 | [servo/stylo](https://github.com/servo/stylo) |

Components that Snowlark uses unchanged are not copied here; `THIRD-PARTY-NOTICES.txt` in each
release lists them with their licences and where their source is.
